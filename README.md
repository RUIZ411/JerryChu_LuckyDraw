# 제리츄 뽑기판 V3.3 — 시작 시점 이후 후원만 수신

## 핵심 변경
- 메인 화면에 `뽑기 시작`과 `후원 수신 종료` 버튼 추가
- `뽑기 시작`을 누른 순간 Apps Script의 현재 마지막 수신 행을 기준으로 저장
- 시작 전에 `대기` 상태였던 후원은 `시작전 제외`로 변경
- 시작 기준 행 이후에 새로 저장된 후원만 사이트 대기열에 등록
- 새로고침해도 진행 중인 수신 세션 유지
- 종료 후 새로 들어온 후원은 다음 시작 시 자동 제외

## GitHub 업로드
저장소의 아래 파일을 V3.3 파일로 교체합니다.
- `index.html`
- `style.css`
- `script.js`
- `assets/mascot-character.png`는 기존과 같으므로 그대로 두어도 됩니다.

## Apps Script
`SOOP_누적집계_제리츄뽑기연동_V3.3_통합본.gs` 전체로 교체한 뒤 새 버전으로 재배포합니다.
기존 `/exec` 주소는 배포를 수정하는 방식이면 그대로 유지됩니다.

## 실제 사용 순서
1. 관리 설정 → 뽑기판에서 상품과 개수 설정
2. `새 뽑기판 생성`
3. 관리 설정 → SOOP 연동에서 연결 설정 저장
4. 메인 화면에서 `뽑기 시작`
5. 시작 버튼을 누른 이후 들어온 후원만 자동 등록
6. 방송 종료 시 `후원 수신 종료`

## 주의
- Apps Script 통합본에는 토큰과 스프레드시트 ID가 포함될 수 있으므로 GitHub에 올리지 마세요.
- `후원 수신 종료`를 눌러도 이미 등록된 대기열은 계속 진행할 수 있습니다.
